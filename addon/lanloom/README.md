# Lanloom add-on

Read-only circuit-board map of your local network, opened from the side panel of your home-automation hub.

See [DOCS.md](DOCS.md) for what the add-on does, its options and how updates work.

**License:** free for private, non-commercial use with up to 100 devices; commercial use requires a paid license. See [LICENSE](https://github.com/robeertm/lanloom/blob/main/LICENSE).
